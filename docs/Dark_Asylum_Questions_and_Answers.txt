PART 6 - RUNESCAPE DATA SOURCES AND SNAPSHOTS
-------------------------------------------------------------------------------
You said there are APIs for clan member info, XP snapshots, and capping/visiting.
I found and tested:
  - Clan roster (RSN, rank, clan XP): official clan hiscores members_lite
  - Per-skill XP: official RS3 hiscores index_lite.json
  - Capping/visiting: the RuneMetrics adventure log API
    ("Capping and visitng is the runemetrics adventure log api")
  - No public RS3 XP-snapshot API exists, so the bot takes its own snapshots.
  - Private RuneMetrics profiles can't be read; those members are flagged and
    admins mark visits/caps by hand.
Examples you gave for reference: lanodra.com (RS3 clan bot features) and
runepixels.com (XP tracking).
Q: How should the API snapshots be limited?
A: First "Once per day", then REVISED: "actually is doable every 6 hours" - the
   snapshot interval is every 6 hours (configurable setting).
Defaults chosen by the build: roster hourly, Citadel log every 30 minutes.
